AI Report Assistant

The AI assistant uses Claude (Anthropic) to parse natural language descriptions of your day into structured report data. You need an API key from console.anthropic.com.

Anthropic API Key
Your key is stored in the app config on the server. Cost: ~$0.003 per report conversation.
How to use
  1. Click the 🤖 AI button in the navbar to open the chat panel
  2. Describe your day's work naturally (Indonesian or English)
  3. The AI will extract data and auto-fill the form fields
  4. Review the filled form, make any corrections, then Generate PDF
